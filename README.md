# 新锐创想官网 UI 第一版

当前版本聚焦品牌开场和武汉大学城服务主页的视觉体验，采用纯 HTML、CSS、JavaScript 实现。

## 已实现

- “新锐创想”四字品牌开场
- 公司六芒金属徽标已完成透明底处理，并用于开场、导航、片区目录、片区详情与网站图标
- 得意黑品牌字体本地嵌入
- 品牌字标与主页标题采用前倾、窄体、斜切收口处理
- Hero 加入基于真实参考车型生成的透明底教练车，保留红色“教练车”字样且不带车辆编号
- 教练车支持驶入、区域切换反馈、鼠标视差倾转、道路与训练桩桶动画
- 大学城切换时车辆提供轻量路线反馈
- 基于公司 Logo 建立深海蓝、钛银、冰蓝与冷白品牌色板
- 冰蓝光带、冷色网格、颗粒、轨道与品牌扫光动画
- 点击进入与跳过动画
- 武汉大学城抽象服务地图
- 武昌中心、光谷东站、藏龙岛、黄家湖、南湖、江夏、轻工大七个正式服务片区
- 汤逊湖、阳逻两个“业务拓展中”片区
- 8 个合作驾校品牌、45 条高校覆盖信息及已知距离
- 按“片区 → 驾校 → 训练场地 → 覆盖高校”动态切换内容
- 首页、片区目录、片区详情采用单屏切换，不需要从首页向下滚动
- 新增“为什么新锐”双幕全屏界面：第一幕聚焦“近、透、配、稳”，第二幕用大学课程表展示在校学车优势
- 优势关键词支持点击特写，课程表空闲时段、学校到训练场路线和教练车提供动态反馈
- 新增九宫格片区目录，可从首页进入，也可在任一详情页直接切换片区
- 详情页采用产品式排版，教练车完整展示，驾校与高校信息集中在决策卡片中
- 进入或切换片区时，教练车从右侧驶入并停靠在独立展示区，不遮挡片区文字
- 支持返回按钮、`Esc` 键和浏览器返回键退出片区详情
- 片区负责人、训练场地状态和缺失距离采用明确占位，不虚构资料
- 同一网址自动适配桌面端、平板与手机，无需维护两套页面
- 手机端提供固定底部导航，可在首页、品牌优势与片区目录之间快速切换
- 手机端优势关键词支持横向滑动，课程安排改为更易阅读的时间轴
- 手机端片区目录采用三页横向滑动，每页集中展示三个片区
- 补充短屏手机与手机横屏布局，避免地图、教练车和底部导航相互裁切
- 平板端提供可展开的全屏导航菜单，覆盖首页、优势、片区与负责人入口
- 手机端片区车辆停车位与辅助字号经过二次校准
- 减少动态效果的系统偏好兼容

## 查看方式

直接打开 `index.html` 即可。首次进入会播放品牌动画，同一浏览器标签刷新后会直接进入主页。

- 强制预览主页：在地址后添加 `?skipIntro=1`
- 直接预览片区：添加 `?skipIntro=1&zone=nanhu`（片区键可查看 `script.js`）
- 重新观看开场：关闭当前标签页后重新打开
